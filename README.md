## 📦 Deployment

### Option 1: GitHub Pages (Recommended - FREE)

1. Create a new repository on GitHub (e.g., `portfolio`)
2. Push this code to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/74927bhushan/portfolio.git
   git push -u origin main
   ```
3. Go to repository Settings → Pages
4. Under "Source", select "main" branch
5. Click Save
6. Your site will be live at: `https://74927bhushan.github.io/portfolio/`

### Option 2: Netlify (FREE)

1. Go to [netlify.com](https://netlify.com)
2. Sign up with GitHub
3. Click "New site from Git"
4. Select your repository
5. Click "Deploy site"
6. Your site will be live with a custom Netlify URL
7. You can add a custom domain in Site Settings → Domain Management

### Custom Domain Setup

Once deployed, you can add your custom domain:

**For GitHub Pages:**
1. Buy a domain (GoDaddy, Namecheap, Google Domains, etc.)
2. Add a `CNAME` file to your repo with your domain name
3. Configure DNS records at your domain registrar:
   - Add CNAME record: `www` → `74927bhushan.github.io`
   - Add A records for apex domain (if needed)

**For Netlify:**
1. Go to Domain Settings in Netlify
2. Add your custom domain
3. Follow the DNS configuration instructions
4. Netlify provides free SSL certificate automatically

## 📝 Customization

To customize the portfolio:

1. **Personal Info**: Update in `index.html`
2. **Colors**: Modify CSS variables in `style.css` (`:root` section)
3. **Profile Image**: Replace `profile.png` with your photo
4. **Content**: Edit sections in `index.html`
